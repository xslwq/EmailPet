# 决策记录

这里保存对未来修改仍有解释价值的工程与产品决策。事实文档只描述现在是什么，决策记录解释为什么这样选择。

## 当前记录

- [0001：采用动态 Agent 事实基线](0001-agent-fact-baseline.md)

## 何时新增记录

满足任一条件时新增 ADR：

- 跨越多个模块或改变组件边界。
- 改变产品副作用、人在环审批或安全边界。
- 改变公共接口、持久化格式或需要迁移。
- 引入长期依赖、难以逆转的约束或明确放弃的替代方案。

局部实现细节、临时进度和可以从代码直接读出的事实不写 ADR。

## 模板

```markdown
# NNNN：决策标题

- 状态：proposed | accepted | superseded
- 日期：YYYY-MM-DD

## 背景

需要解决的问题、约束和证据。

## 决策

选择了什么，以及明确不选择什么。

## 后果

收益、代价、迁移要求与后续维护触发条件。

## 关联事实

当前事实文档和关键代码路径。
```

决策被替代时保留原文件，将状态改为 `superseded` 并链接新记录；不要修改历史使其看起来从未发生。
